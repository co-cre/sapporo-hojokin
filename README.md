# 札幌の補助金・助成金

札幌の中小企業・個人事業主が使える、国・北海道・札幌市の補助金を毎朝集めて1枚の一覧にする。

```text
毎朝6時（daily）   情報源から集める → data/subsidies.json（差分がコミット履歴になる）→ public/index.html → GitHub Pages
1時間ごと（jnet21-hourly）  J-Net21 の北海道・札幌の新着だけ溜める
```

## 動かす

```sh
python3 collect.py   # 集める（標準ライブラリだけ）
python3 build.py     # public/index.html を作る
```

## 情報源と載せ方

| 情報源 | 取り方 | 載せるもの |
|---|---|---|
| jGrants（デジタル庁） | 公開API。ポータルHTMLは robots.txt で禁止なので取らない | 名前・実施機関・上限額・受付期間・リンク |
| 北海道 中小企業課 | HTML一覧（CC BY） | タイトル・リンク |
| 札幌市 新着情報 | RSS。産業・ビジネス分野の補助・助成だけ | タイトル・リンク（本文の転載は許諾が要る） |
| J-Net21（中小機構） | RSS。札幌市・北海道のものだけ | タイトル・リンク（本文の転載不可） |

要約は載せない。締切・金額の誤案内を防ぐため、内容は必ずリンク先の公式情報で確かめてもらう。

## 設定

- `config.json` の `line_url` を入れると、1画面目にLINE相談の導線が出る（空なら出さない）
- リポジトリの Secrets に `SLACK_WEBHOOK_URL` を入れると、毎朝の更新が失敗したときにSlackへ知らせる
